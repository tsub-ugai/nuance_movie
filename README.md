# ヌュ動画帳

アイドルグループ **NUANCE（ヌュアンス）** の公式X [@nuance_official](https://x.com/nuance_official) に投稿されたライブ映像を、楽曲ごとにまとめた非公式のファンアーカイブです。

**公開URL: https://tsub-ugai.github.io/nuance_movie/**

## できること

- 楽曲ごとにクレジット（作詞・作曲・編曲・振付）を集約して表示
- その曲が収録された映像を、公演単位（日付・会場・イベント名）で一覧
- 曲名・人名・会場・イベント名でのキーワード検索
- 作詞／作曲／編曲／振付／会場／イベント／年での絞り込み（人名や会場名のクリックでも可）
- 並び替え（映像が新しい順・映像が多い順・曲名順）

## 収録範囲

2023年7月〜2026年9月に投稿された、**曲名と作詞・作曲者名が明記された**ライブ映像。28曲・46本。

公式アカウントが「曲名＋クレジット」を添えて映像を投稿する形式は2023年7月頃から確認できるため、それ以前の映像は収録していません。

## データの更新方法

`index.html` 内の `SONGS` 配列を編集します。ビルド不要の単一HTMLファイルです。

```js
{ t:"曲名", ly:"作詞", co:"作曲", ar:"編曲", ch:"振付", videos:[
  { d:"2026-09-10", venue:"会場名", event:"イベント名", id:"ツイートID" }
]}
```

- `ar`（編曲）・`ch`（振付）は無ければ省略可
- `id` は `https://x.com/nuance_official/status/` に続く数字部分
- 1本の動画に複数曲が入っている場合は、各曲に同じ `id` を登録し `note` で補足

## 注記

- クレジットは各投稿の表記に基づきます。「特急 元町・中華街行き27分」は投稿によって表記が異なるため、より詳しい2025年6月の表記を採用しています。
- 「森尻有希子」と「yukiko（miyumiyu）」は同一人物のため名寄せしています。
- 本サイトはファンによる非公式のまとめであり、NUANCEおよび関係各社とは関係ありません。
